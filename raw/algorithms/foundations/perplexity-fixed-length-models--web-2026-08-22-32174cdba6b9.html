Perplexity of fixed-length models

Perplexity is the exponentiated average negative log-likelihood of a token sequence. For an autoregressive language model, PPL(X) = exp(-1/t * sum(log p_theta(x_i | x_<i;))).

The tokenization procedure directly affects perplexity, so scores should be compared only when tokenization and evaluation data are aligned. The metric is specific to causal/autoregressive language models and is not well defined for masked language models such as BERT.

Fixed-length evaluation

Disjoint chunks waste context and usually produce a worse score. A sliding-window or strided sliding-window evaluation gives each target token more preceding context. The targets used only as context must be masked from the loss.

avg_nll = nll_sum / n_tokens
ppl = torch.exp(avg_nll)

The guide reports GPT-2 evaluation at 19.44 PPL with stride 1024 and 16.44 with stride 512, illustrating that the evaluation protocol changes the number.
