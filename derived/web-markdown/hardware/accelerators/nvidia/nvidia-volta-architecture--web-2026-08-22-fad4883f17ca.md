### 640 Tensor Cores

An Exponential Leap in Performance

Every industry needs AI, and with this massive leap forward in speed, AI can now be applied to every industry. Equipped with 640 [Tensor Cores](https://developer.nvidia.com/tensor_cores), Volta delivers over 125 teraFLOPs per second (TFLOPS) of deep learning performance, over a 5X increase compared to prior generation NVIDIA Pascal™ architecture.

![New GPU Architecture](https://www.nvidia.com/content/dam/en-zz/es_em/Solutions/Data-Center/volta-architecture/data-center-volta-new-gpu-625-ud.jpg)

### New GPU Architecture

Engineered for the Modern Computer

Humanity’s greatest challenges will require the most powerful computing engine for both computational and data science. With over 21 billion transistors, Volta is the most powerful GPU architecture the world has ever seen. It pairs NVIDIA ® CUDA ® and Tensor Cores to deliver the performance of an AI supercomputer in a GPU.

![NVIDIA NVLink2](https://www.nvidia.com/content/dam/en-zz/es_em/Solutions/Data-Center/volta-architecture/data-center-volta-nvlink2-625-ud.jpg)

### Next Generation NVLink

Scalability for Rapid Time-to-Solution

Volta uses next generation revolutionary NVIDIA NVLink ™ high-speed interconnect technology. This delivers 2X the throughput, compared to the previous generation of NVLink. This enables more advanced model and data parallel approaches for strong scaling to achieve the absolute highest application performance.

![Volta-Optimized Software](https://www.nvidia.com/content/dam/en-zz/es_em/Solutions/Data-Center/volta-architecture/data-center-volta-optimized-625-ud.jpg)

### Volta-Optimized Software

GPU-Accelerated Frameworks and Applications

Data scientists are often forced to make trade-offs between model accuracy and longer run-times. With Volta-optimized CUDA and [NVIDIA Deep Learning SDK libraries](https://developer.nvidia.com/deep-learning-software "NVIDIA Deep Learning SDK libraries") like [cuDNN](https://developer.nvidia.com/cudnn "cuDNN"), NCCL, and [TensorRT](https://developer.nvidia.com/tensorrt "TensorRT"), the industry’s top frameworks and applications can easily tap into the power of Volta running [mixed precision](https://developer.nvidia.com/automatic-mixed-precision "cuDNN"). This propels data scientists and researchers towards discoveries faster than before.
